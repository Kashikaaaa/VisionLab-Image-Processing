# VisionLab: Image Processing and Edge Detection Studio

VisionLab is an interactive image-processing application built using Python, OpenCV, and Streamlit.

It allows users to upload an image and apply different image-processing techniques such as grayscale conversion, Gaussian blur, edge detection, and binary thresholding.

## Features

- Upload images in common formats
- Convert images to grayscale
- Apply Gaussian blur
- Detect edges using the Canny Edge Detection algorithm
- Apply binary thresholding
- Display image statistics
- Download processed images
- Interactive and user-friendly Streamlit interface

## Technologies Used

- Python
- OpenCV
- NumPy
- Pillow
- Streamlit
